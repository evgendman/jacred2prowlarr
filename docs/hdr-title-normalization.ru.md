# Нормализация HDR-меток по названию релиза

## Область действия

Текущая схема JSON JacRed содержит общий признак `info.videotype` (`hdr` или `sdr`), но не предоставляет достаточно полных и стабильных метаданных для различения HDR10, HDR10+ и Dolby Vision. Поэтому адаптер нормализует эти метки **только по исходному названию релиза**.

Это **подсказки, извлечённые из названия**, а не утверждение, что видеопоток был независимо проанализирован. Нельзя выводить конкретный HDR-стандарт из кодека, разрешения, разрядности или `info.videotype`.

## Канонические метки

| Метка в нормализованном названии | Доказательство в исходном названии |
|---|---|
| `HDR10` | Явный токен `HDR10`, не являющийся началом `HDR10+` |
| `HDR10+` | Явный токен `HDR10+` или `HDR10 Plus` |
| `Dolby Vision` | Явное `Dolby Vision` или `DoVi`; токен `DV` — только вместе с профилем/версией или контекстным HDR/UHD-признаком в том же названии |
| `HDR` | Общий токен `HDR` / `HDR+`, если более конкретный HDR-формат не указан |
| `SDR` | Явный токен `SDR`, только если HDR-метки отсутствуют |

Порядок меток фиксирован: `HDR10`, `HDR10+`, `Dolby Vision`. Общая `HDR` не добавляется повторно, если указан конкретный HDR-формат. Неоднозначный `DV` без контекста игнорируется; распознаваемые примеры: `DV 8.1`, `DV P8`, `HDR10 DV` и `4K DV`. Отдельный `HDR+` не считается `HDR10+`.

## Размещение в нормализованном названии

Метки добавляются к нормализованному сегменту качества при любом разрешении, например:

- `Lanterns S01E01 (2026) WEB-DL 2160p HDR10+ Dolby Vision`
- `Lanterns S01E01 (2026) WEB-DL 1080p HDR10+`
- `Example Movie (2024) WEB-DL 2160p HDR10`
- `Example Movie (2024) WEB-DL 1080p SDR`

Если разрешение не удалось определить, метки из названия всё равно сохраняются. Исходное название JacRed остаётся после разделителя `***`, поэтому исходная формулировка доступна для проверки.

## Практические последствия

- Custom Formats Sonarr/Radarr могут искать устойчивые канонические токены в нормализованном названии.
- Если в исходном названии явно указаны `HDR10+ Dolby Vision`, сохраняются обе метки; адаптер не добавляет стандарт, отсутствующий в исходном названии.
- Значение `info.videotype=hdr` без HDR-маркеров в `Title` не приводит к созданию HDR-метки.
- Наличие метки не доказывает, что файл действительно содержит такой формат. Название может быть ошибочным; нормализация по названию сохраняет заявленную характеристику, не выдавая её за проверку видеопотока.
